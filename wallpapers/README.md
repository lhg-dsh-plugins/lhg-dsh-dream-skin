# 壁纸 / Wallpapers

这里放你找来的、想用于 dsh-dream-skin 的壁纸图。它们会随本仓库一起存在，但**默认不打进 npm 包**（保持包体积小、也避免素材授权问题）。

## 怎么用

1. 把图片拖进本目录（`.jpg` / `.png` / `.webp`）。
2. 在 DSH 里：**设置 → 外观（Theme）→ 背景图片 → 选择图片**，选本目录里你想用的那张。
3. 插件会把图压缩成 data URL，只保存在**当前浏览器**里（不产生网络上传）。

换肤、换壁纸、调透明度/模糊后，**刷新不丢**（localStorage）。

## 说明

- 这里只是**文件组织用的目录**。插件加载壁纸走 DSH 界面（选图 → 存到浏览器），并不直接从本目录读取，这样任何用户都不需要下载本仓库的图就能换壁纸。
- 请只放你有权使用的图片。如果你要**发布 / 分发**某张壁纸（比如收进主题包、或在 GitHub 上公开），务必确认素材版权。
- 不想让某张图进 git？在 `wallpapers/` 下加一个 `.gitignore`，或干脆不放本目录。
